# osedaniassurfhouse

Modern blue-and-white animated surf destination website for Oseda Nias Surfhouse.

## Included

- Multi-page section-based website
- Home/Hero page (`index.html`)
- About page (`about.html`)
- Rooms page (`rooms.html`)
- Gallery page (`gallery.html`)
- Reviews page (`reviews.html`)
- Location page (`location.html`)
- Booking/Strong CTA page (`booking.html`)
- Responsive layout for desktop, tablet, and mobile
- Fully icon-rich UI using Font Awesome
- Animated sections (hero motion, floating cards, reveal-on-scroll, WhatsApp pulse CTA)

All required sections are available as separate linked pages from the top menu.

## Assets

- Styles: `assets/css/styles.css`
- Scripts: `assets/js/main.js`

## Notes

- Replace placeholder WhatsApp number (`6281234567890`) with your real booking number.
- Replace image URLs with your own photos for final production use.
- The structure and sections are designed to be easily rebuilt inside WordPress + Elementor if needed.
